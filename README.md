# Koni Clean — funkcionalni prijedlog stranice

Javni demo redizajna za [koniclean.hr](https://koniclean.hr/). Nije službena stranica.

Što je popravljeno u odnosu na postojeći site:

- jedan primarni telefon
- Zagreb (operativa) i Ploče (sjedište) razdvojeni
- ispravan poštanski broj 10000
- radni kalkulator cijene
- kontakt forma koja otvara WhatsApp
- karta
- cjenik bez proturječnih minimuma
- bez lažnih recenzija i slomljenog videa

Repo: javni, za pregled s Vercela.
